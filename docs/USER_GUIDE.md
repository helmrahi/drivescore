# Guide utilisateur DriveScore

## Pour le conducteur

### 1. Creer un compte
1. Aller sur https://drivescore-eight.vercel.app
2. Cliquer Creer mon compte gratuitement
3. Remplir prenom, nom, email, telephone
4. Creer un mot de passe
5. Accepter les deux consentements CNDP
6. Cliquer Creer mon compte DriveScore

### 2. Declarer un trajet manuellement
1. Dashboard -> + Trajet
2. Saisir les km parcourus
3. Choisir le type de route
4. Indiquer ville depart et arrivee
5. Declarer les incidents
6. Cliquer Enregistrer

### 3. Utiliser la telematique GPS
1. Dashboard -> bouton voiture
2. Cliquer Demarrer le trajet
3. Autoriser GPS et capteurs
4. Conduire normalement
5. Cliquer Terminer le trajet
6. Verifier le resume et Sauvegarder

### 4. Comprendre son score
- 90-100 : Excellent -> -15% sur la prime
- 80-89  : Bon -> -10% sur la prime
- 70-79  : Moyen -> -5% sur la prime
- moins de 70 : A ameliorer -> pas de reduction

### 5. Strategie de branches Git
- main    -> production (Vercel auto-deploy)
- develop -> integration
- feature/nom -> nouvelles fonctionnalites
- fix/nom -> corrections
